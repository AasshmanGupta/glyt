# Versioning

Glyt versions describe project maturity, not just implementation completeness.

## 0.x

The language may change substantially.

Foundational assumptions are open to research and revision.

## 0.1.0

Foundation Rebuilt.

This version establishes the modern project identity and collaboration surface.

## Future minor versions

Minor versions may represent meaningful discoveries in philosophy, language design, experiments, tooling, or implementation.

## 1.0

1.0 should mean that Glyt has demonstrated enough stability, capability, usability, safety, and real-world value to be trusted as a serious language.

A version number must never become an excuse to freeze a bad idea.
