# Project Status

## Version

**0.1.0 — Foundation Rebuilt**

## What exists

Glyt currently has a coherent project philosophy and a defined set of design constraints.

The repository is ready for collaborative language discovery.

## What does not exist yet

The concrete language grammar is not finalized.

The syntax is not finalized.

The type system is not finalized.

The implementation strategy is not finalized.

This is intentional.

## Current priority

The immediate priority is to discover what language design best fulfills Glyt's stated human experience and capability goals.

## Contributor readiness

The repository is explicitly open to:

- programming-language research
- education research
- usability research
- design experiments
- syntax experiments
- conceptual architecture
- examples
- documentation
- accessibility work
- domain expertise
- implementation experiments

## Relationship to Loom

Separate project.

Loom may eventually provide transformation infrastructure for Glyt, but Glyt's current work is language design.
