# Glyt Manifesto

1. Creation should feel exciting.
2. A language should grow with its creator.
3. Solve creator problems, not language-complexity problems.
4. Simplicity is a beginning, not a limit.
5. Beauty matters because humans live inside what they create.
6. Every useful abstraction should have a path toward deeper understanding and control.
7. Respect developer intent.
8. One coherent language should be able to travel across domains.
9. Projects should feel alive while they are being made.
10. Convenience should never become a prison.
11. Reward curiosity through capability, not manipulation.
12. Leave the creator more capable than before.
