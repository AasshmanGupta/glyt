# Conceptual Architecture

This is a conceptual map, not a finalized implementation architecture.

## Layer 1 — Human intent

The creator has an idea, goal, question, or desired outcome.

## Layer 2 — Glyt expression

The creator expresses that intent using Glyt's eventual language and tooling.

## Layer 3 — Core concepts

A small set of fundamental language concepts should underpin the larger surface.

## Layer 4 — Derived capabilities

Convenience commands, domain vocabulary, libraries, and abstractions should be able to build on the core.

## Layer 5 — Deeper control

Users can descend toward lower-level interfaces and more explicit mechanisms when needed.

## Layer 6 — Execution and integration

Programs ultimately interact with operating systems, hardware, networks, files, libraries, services, and other software.

## Architectural rule

The layers should not become separate languages that users must mentally abandon and relearn whenever they descend.

The exact mechanisms connecting these layers remain open research questions.
