# Licensing Status at Glyt v0.1.0

| Area | Current status |
|---|---|
| Glyt implementation | GPLv3 intended; root `LICENSE` contains the official GPLv3 text |
| Runtime exception | Draft only; not yet adopted |
| Documentation / specification / research | CC BY 4.0 notice in `LICENSE-DOCS` |
| Independent implementations | Not governed by Glyt implementation license when independently written |
| Software made with Glyt | Intended to remain under the creator's chosen license, subject to incorporated components |
| Contributions | Contributor retains ownership; project needs permanent rights to accepted contributions |
| Glyt name / logo | Separate policy in `TRADEMARKS.md` |
| Security disclosure | Policy in `SECURITY.md` |

This status describes project intent, not a substitute for the full legal text
of any applicable license.
