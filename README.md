# Glyt

> Advancement without losing soul.

Glyt is an experimental universal programming language designed around one question:

> What would the ideal programming language look like if it were designed today?

Rather than focusing on one domain, Glyt aims to provide a single language capable of creating software across every domain while remaining beginner-friendly and expert-capable.

## Vision

One language.

Infinite possibilities.

From tiny scripts to operating systems.

From games to artificial intelligence.

From websites to scientific simulations.

Glyt grows with its creator.
