# Syntax

## Status: intentionally undecided

Glyt's concrete syntax is **not finalized in v0.1.0**.

This is deliberate.

The repository should not commit to punctuation, keywords, formatting rules, or grammar merely to make an early release look complete.

## What belongs here right now

Syntax experiments, prototypes, comparisons, and research-backed proposals.

An experiment is not automatically a final decision.

## Proposal standard

A syntax proposal should explain:

1. What problem it solves.
2. Why that problem matters to creators.
3. How beginners encounter it.
4. How experts use it.
5. What deeper concepts it exposes.
6. What trade-offs it introduces.
7. What existing approaches were considered.

## One language rule

Different domains may receive different vocabulary, but competing domain grammars should not silently fragment Glyt.

## Experimental freedom

Radical proposals are welcome.

Glyt is willing to discover that a traditional programming-language syntax is not the best architecture for the goal, provided the resulting system still meaningfully controls computers and serves the project mission.
