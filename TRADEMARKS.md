# Glyt Name and Branding

## Purpose

Glyt is an open project. Its code and documentation are intended to be freely
usable under their applicable licenses. The Glyt name and visual identity are
a separate matter from copyright licensing.

This policy is intended to make it easy to build on Glyt without making it
unclear which project is the official Glyt project.

## Truthful use

You may truthfully describe software as:

- built with Glyt,
- compatible with Glyt,
- based on Glyt, or
- a modified version or fork of Glyt,

provided that the description is accurate and does not falsely imply official
status, endorsement, or authorship.

## Official status

The terms "official Glyt", "Glyt project", and similar wording should not be
used to imply that a fork, derivative distribution, commercial product, or
third-party service is maintained or endorsed by the official Glyt project
unless that is actually true.

A fork may use its own name. A modified implementation should be clearly
distinguishable from the official project when that distinction matters to
users.

## Name changes

Nothing in a Glyt copyright license grants ownership of the Glyt trademarks
or branding. Copyright permissions and trademark permissions are separate.

This document is a project policy, not a grant of trademark rights. Any future
formal trademark registration or policy may replace or refine it.
